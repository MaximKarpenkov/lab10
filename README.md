# Лабораторная работа 10. Текстовые файлы и обработка ошибок

## Как запустить
1. Демонстрация: `python main.py`
2. Проверки: `python test_files.py`

---

## Структура файлов
- `files_lab.py` — `read_matrix`, `selected_sum`, `export_csv`.
- `table.py` — `row_sums`, `column_sums` (из работы №9).
- `main.py` — надёжный ввод, чтение, отчёт, CSV-экспорт.
- `test_files.py` — проверки через `TemporaryDirectory`.
- `matrix.txt` — входные данные.
- `report.txt` — пример отчёта.

---

## Формат `matrix.txt`
2 3
1 -2 3
4 0 -6

text
- Первая строка: **R C** — два положительных целых.
- Далее **R** строк по **C** целых чисел.
- Один пустой перевод строки в конце допустим; лишние и пустые строки — ошибка.

---

## Проверки

| Содержимое / ситуация | Ожидаемое поведение | Факт |
|---|---|---|
| `1 2\n7 -1\n` | `[[7, -1]]` | Совпадает |
| `1 1\n0\n` | `[[0]]` | Совпадает |
| Пустой файл | `ValueError` | Совпадает |
| `0 3\n` | `ValueError` | Совпадает |
| `1 2\n1\n` | `ValueError` с номером строки 2 | Совпадает |
| `1 2\n1 x\n` | `ValueError` с номером строки 2 | Совпадает |
| `1 1\n0\n1\n` | `ValueError` (лишняя строка) | Совпадает |
| Отсутствующий путь | `FileNotFoundError` | Совпадает |

### Вариант 1
`selected_sum([[1, -2, 3], [4, 0, -6]]) == 8` (1 + 3 + 4).

### Сохранность старого отчёта
При вводе с ошибкой (например, изменённый `matrix.txt` с неверной формой)
программа **не** открывает `report.txt` на запись — прежний отчёт остаётся без изменений.
Это проверено вручную: старый `report.txt` сохранился.
